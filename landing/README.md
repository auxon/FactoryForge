# FactoryForge Landing

React + Vite landing page for **FactoryForge**, built from the game splash screen and asset art.

## Prerequisites (Windows)

1. Install [Node.js LTS](https://nodejs.org/) (includes `npm`).
2. Open a terminal in this folder:

```bat
cd landing
```

## Install & run

```bat
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Local development server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Lint with oxlint |

## Assets

Game images are copied into `public/assets/` from `FactoryForge/Assets/` (splash, machines, science packs, etc.).
